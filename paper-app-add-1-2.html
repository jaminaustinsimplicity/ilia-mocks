Dev notes · what changes vs today

  1. New order: Agent → IMO → Carrier & product → Client → Create. Today it's Type/Carrier → Client → Agent.
  2. "Invite a new agent" is removed. Only existing ILIA agents can be picked, so no On Hold / pending-agent path.
  3. IMO step is new. Agent has 1 IMO → shown, auto-selected. More than 1 → admin must pick one. (Today ILIA picks the IMO silently.)
  4. Carrier then ilia Product Type, the same pattern as the agent's "Create a new invitation" screen. Securian or Symetra → exactly one product: "Kai-Zen Paper Workflow", auto-selected. Replaces the old "Paper Application Type" box.
  5. Carriers (MVP): Securian and Symetra only. Both map to the single product "Kai-Zen Paper Workflow".
  6. Agent search = active agents only. Agent with no IMO → message + Create blocked.
  7. On create: admin lands on the new client's page (today: participants list). Emails + action item are ST-3 (shown here for context).
