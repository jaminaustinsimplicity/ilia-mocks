Partner IUL + Kai-Zen Boost: Workflow

ILIA agents in Judy's and Josh's IMOs want to sell IUL with a Kai-Zen boost. Simplicity provides no IUL-upsell marketing in ILIA, so agents do their own marketing in J's Partner Hub CMS, outside ILIA. Every CMS link belongs to an agent whose CMS account is tied to their ILIA account (their ILIA login email, confirmed by their IMO). Each client is added in ILIA by the agent who brought them. ILIA is only the enrollment engine, and v1 needs no new ILIA code.

Attribution chain

How every client is traced from outside marketing to the agent in ILIA.

Agent in ILIA (Judy's / Josh's IMO)→ CMS account ↔ ILIA login email (IMO-confirmed)→ CMS link / asset ID→ Anonymous funnel→ IUL or Kai-Zen→ Details at account step→ Agent adds client in ILIA → tied to them
The link needs nothing from ILIA. The CMS knows which agent owns each link; that agent adds the client from their own ILIA account, so ILIA ties the client to them with no new code.
