Dev notes · T-3 action item

  1. New action item type: "Complete Paper App Details", created when the admin clicks Create Paper Application (T-1). It shows in NIW Action Items (type Enrollment) with a PAPER tag.
  2. Button "Complete Details" opens a side panel: paper-app summary, what's still needed, and which emails went out at creation.
  3. The "Go to…" links open that client's page (Client Profile / Documents tab). Admin, agent and client can all fill these in.
  4. "Mark details complete" checks off the item. If something still looks missing, the admin gets a warning but can still continue.
  5. On complete: the item moves to Completed action items, and the next item "Mark Application Sent to Carrier" is created (that step is T-8).
  6. Paper apps no longer jump straight to "Upload & Send Proposal" at creation.
Try it
Click Complete Details on the highlighted row. Use the "pretend" toggles in the panel to see the complete vs missing states.
