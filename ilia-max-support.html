ILIA Support Max

Support Max is an in-product AI copilot for ILIA admins. It answers ILIA & Kai-Zen questions from live documentation and data, files bugs straight to Jira, captures product ideas, and surfaces the exact FullStory session behind an issue — all inside the ILIA screen the admin is already on. This page is the living reference for what it does.

Support Features

What Support Max can do today, organized by category. Each capability runs read-only and draft-only — Max never changes ILIA data or sends anything on its own.

💬 Conversational Support Live

Ask about ILIA or a client in plain language and get a grounded, honest answer.

  • ILIA & Kai-Zen Q&A — how workflows, screens, and strategies work.
  • Grounded in the live ILIA Confluence space — answers reflect your actual documentation, not a static script.
  • Live data lookups — client & servicing details, documents, and more, pulled on demand.
  • "Thinking…" indicator — you always see when Max is working.
  • Remembers your recent context — greets you back and picks up where you left off.
  • "Which person?" picker — when a name matches several people, you pick the exact one before any data is shown.

🐞 Bug Reporting Live

File a real Jira bug from the ILIA screen — no context-switching.

  • Lands in a "Reported Bugs" intake — set to Needs Clarification, never dropped into an active sprint.
  • Auto-assigned to the triage owner so nothing falls through the cracks.
  • Structured capture — title, what happened, where it happens, who's affected, and priority (mapped to Jira's real Priority field).
  • Screenshots → Jira attachments — drag, paste, or choose files; remove on hover.
  • Add FullStory — look up the client's sessions by email and attach the right replay to the ticket.
  • Guardrails — required fields, and a submit lock so a bug can't be double-filed.

💡 Idea Capture Live

Turn an admin's suggestion into something the team actually sees.

  • File a product idea in a sentence or two, with impact.
  • Routed to the ILIA Feature Ideas board for the tech team & leadership to review.
  • Nothing sent elsewhere — it's captured, not emailed.

🎬 Session Insight (FullStory) Live

See exactly what a client did on screen — without leaving ILIA.

  • Find sessions by client email — no separate FullStory login/search.
  • Grouped by day, newest first, so you can match the session to when the call happened.
  • View or attach the right session, with easy add/remove.
  • Free team viewing via domain-locked guest access — only your people can watch.

📊 Reporting (Domo) In progress

Two-way connection to Domo for adoption dashboards and in-chat reporting.

  • Usage → Domo — Max logs its own activity so leadership can dashboard adoption.
  • Domo → Max — ask reporting questions in chat and get answers from Domo data.
  • Pending Domo access setup.

🔒 Built-in Safeguards Live

Security is on by default — summarized here, detailed in the Security tab.

  • Read-only & draft-only — never edits ILIA, never sends a message on its own.
  • Confirms which person before showing client data; never dumps full records.
  • Stays in its lane — an ILIA support agent only; resists off-topic or manipulation attempts.
  • Every sensitive action is logged to an audit trail.
