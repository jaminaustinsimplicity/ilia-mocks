How the Support Agent runs on AWS

The Support Agent's "brain" is Claude. In production it runs Claude through Amazon Bedrock inside NIW's own AWS — so client data never leaves our environment and never reaches Anthropic.

The agent is built & tested — this is the connection change that clears the security gate
Why the change

Testing only

ILIA → Anthropic's API. Simple, but Anthropic retains inputs & outputs for 30 days (no Zero-Data-Retention on our plan). Fine for knowledge / PII-free testing — not for real client data.

Production

Our AWS → Bedrock. Same Claude models, but the call runs inside NIW's AWS account under our data terms. Client data stays in-house — real client data is fine.

⚙️ What Mohit sets up on AWS — NIWD-2270

A one-time enablement. No Anthropic key and no AWS access key in the code — access is the IAM role alone.

  1. Enable Amazon Bedrock + Claude model access in us-east-1.
  2. Create an IAM role scoped to bedrock:InvokeModel for the backend to assume — no keys issued.
  3. Host the Support Agent backend and expose an HTTPS endpoint.
Then hand back three values: endpoint URL · region · model id. That's all the dev side needs to wire it in.

🔒 The guarantee

Because the model runs in NIW's AWS via an IAM role, client PII never reaches Anthropic — exactly what the security review requires. The agent's guardrails carry over:

Strips PII before the model Confirms which person first Read-only — never edits ILIA Draft-only — never sends Fixed, validated output Says so when unsure
What happens next

When Mohit returns endpoint · region · model id → the dev side makes a small connection swap (point the agent at Bedrock instead of the Anthropic API — everything else, prompts and tools and guardrails, stays the same), then runs a zero-PII smoke test through Bedrock to confirm it behaves identically. After that: real-data validation, then the security review.

✅ The Bedrock path is already proven — a reference test in the PM-portal project returned "Bedrock is working." We reuse that same enablement; nothing experimental.  ·  Tracked in NIWD-2270.
